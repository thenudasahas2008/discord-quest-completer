# ⚡ Discord Quest Completer Pro (v3.0.0)

> Complete any active Discord gameplay quest automatically with zero game installations, unlimited runtime mode, and real-time Discord IPC rich presence simulation.

---

## ✨ Features

- **🚀 Zero Game Installation Required:** Spoofs Windows process metadata so Discord detects you are actively playing the required game.
- **⚡ Dual-Engine Detection:**
  - **Native Win32 Spoofer Engine:** High-performance background process simulator.
  - **Discord IPC Pipe (`\\.\pipe\discord-ipc-0`):** Direct Rich Presence broadcast for infallible activity detection.
- **🎮 10,500+ Verified Games Database:** Pre-indexed list of all Discord-detectable games, including:
  - *Call of Duty: Modern Warfare III / Black Ops 6 / CoD 4*
  - *Marvel Rivals*
  - *Monster Hunter Wilds*
  - *Apex Legends*
  - *Brawlhalla*
  - *Fortnite* and 10,000+ others.
- **⏱ Unlimited Runtime Mode:** Live count-up stopwatch (`00:00:00`) that runs until you decide to stop.
- **🧪 1-Click Connection Test:** Instantly test live Discord detection and rich presence with a single click and direct stop control.
- **🔍 60 FPS Ultra-Fast Search:** Real-time debounced search indexing across 10,500+ titles with pagination.
- **➕ Custom Game Support:** Add any custom quest executable directly.

---

## 📥 Download & Usage

1. Go to the [Releases](https://github.com/thenudasahas2008/discord-quest-completer/releases) page.
2. Download **`DiscordQuestCompleter.exe`**.
3. Make sure your Discord desktop app is open.
4. Double-click `DiscordQuestCompleter.exe` (no installation required).
5. Search for the quest game (or click **Test Connection**) and hit **LAUNCH ▶**.
6. When your quest is completed in Discord, click **⏹ STOP QUEST**.
